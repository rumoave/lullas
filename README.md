# Lulla's Foundation

Earthquake relief for Venezuela, from the families of Casa Ora and Lulla's Bakery in Brooklyn.

Single-file static site. Deploys anywhere (Vercel, Netlify, GitHub Pages).

- `index.html` - the site (brand assets embedded)
- `media/lullas-ground.mp4` - "Desde el terreno" section video
- `clips/venezuela-01.mp4` - hero background clip. Add venezuela-02 through -04 to extend the rotation.
